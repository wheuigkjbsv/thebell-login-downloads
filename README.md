# 더벨 로그인

로그인 앱과 Masterkey 브라우저 확장기능을 내려받는 공개 배포 페이지입니다.

## 다운로드

- [애니메이션 사용설명서](https://github.com/wheuigkjbsv/thebell-login-downloads/releases/latest/download/login-guide.html) — 내려받은 HTML 파일을 브라우저에서 여세요.
- [더벨 로그인 앱 (Windows)](https://github.com/wheuigkjbsv/thebell-login-downloads/releases/latest/download/thebell-login.exe)
- [Masterkey 확장기능 (Chrome·Edge)](https://github.com/wheuigkjbsv/thebell-login-downloads/releases/latest/download/masterkey-chrome.zip)

## 처음 사용한다면

1. 로그인 앱을 실행하고 가진 계정만 입력해 로그인합니다.
2. 확장기능 ZIP의 압축을 풀고 브라우저 확장 관리 화면에서 개발자 모드를 켠 뒤 폴더를 로드합니다.
3. 일반 웹페이지에서 Masterkey 열쇠 버튼을 눌러 브라우저에 로그인합니다.

세부 설치 순서는 사용설명서에서 애니메이션으로 확인할 수 있습니다. 설명서 안의 다운로드 링크도 공개 파일로 연결됩니다.

뉴스클립 앱과 개발 저장소는 이 배포에 포함되지 않습니다.
